# JavaScript Weather App

A simple Weather App built with HTML, CSS, and JavaScript. This project allows users to search for a location and view its current weather information through a clean and interactive interface.

## 🚀 Features

- Search weather by city
- Display current weather information
- Show temperature
- Display weather conditions
- User-friendly interface
- Dynamic weather data
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API

## 📚 Concepts Practiced

- DOM Manipulation
- Event Handling
- Functions
- User Input
- API Integration
- Fetch API
- JSON Data
- `async/await`
- Conditional Statements
- Template Literals

## 🎯 Purpose

The purpose of this project is to practice JavaScript API integration, fetch weather data, work with JSON responses, and dynamically display information on a webpage.
